# 🏠 Khan Amlak

A modern real-estate marketplace built with **HTML, CSS, and JavaScript** that allows users to browse, post, and manage property listings with an interactive user experience.

## ✨ Features

### 🔐 Authentication

* User Registration
* User Login
* Logout System
* User Profile Page

### 🏠 Property Management

* Create Property Listings
* Edit Listings
* Delete Listings
* View Property Details
* Property Gallery Support
* Property Location Support

### 🔍 Search & Filters

* Live Search
* Filter by City
* Filter by Property Type
* Filter by Price Range
* Filter by Area

### ❤️ Favorites System

* Add Properties to Favorites
* Remove Favorites
* Favorites Section in User Panel
* Empty State Messages

### 💬 Chat System

* Private Property Chat Rooms
* Send Messages with Enter Key
* Message Timestamps
* Seen Status (✓ / ✓✓)
* New Message Notifications

### 📞 Contact Requests

* Send Contact Requests to Property Owners
* View Contact Requests in User Panel
* Request History

### 🎨 User Experience

* Dark Mode
* Responsive Design
* Mobile Friendly
* Tablet Friendly
* Scroll Progress Indicator
* Back To Top Button
* Toast Notifications

### 👤 User Dashboard

* Personal Information
* Profile Picture Support
* My Properties Section
* Favorite Properties Section
* Contact Requests Section
